Конструктор профессиональных объявлений

Выберите профессию и услугу — сайт подготовит конструктор именно для вашего случая.

Руководство пользователя

1. Выберите профессию

Выберите профессию из списка или найдите её через строку поиска.

2. Выберите услугу

Для каждого объявления можно выбрать только одну услугу. Поставьте одну галочку и нажмите «Дальше».

Для другой услуги вернитесь к списку и выберите другую.

3. Выберите направления работы

Отметьте подходящие специализации. Можно выбрать несколько пунктов.

4. Укажите, как вы работаете

Отметьте подходящие варианты режима работы. Текст можно исправлять прямо в строках.

5. Выберите преимущества

Отметьте подходящие преимущества. Можно выбрать несколько пунктов и изменить их текст.

6. Заполните контакты

Укажите имя или компанию, город, телефон, сайт, E-mail и цену. Затем нажмите «Создать объявление».

Работа с готовым объявлением

Редактировать данные — изменить выбранные пункты и контакты.

Редактировать текст объявления — вручную исправить готовый текст.

Копировать текст — скопировать объявление. Для вставки используйте Ctrl + V.

Скачать TXT — сохранить объявление как текстовый файл.

Сохранить HTML-страницу — сохранить страницу со всеми введёнными данными.

Открыть проект — выбрать ранее сохранённый файл проекта JSON.

Создать страницу специалиста — сформировать персональную мини-страницу из уже введённых данных, просмотреть её и скачать отдельным HTML-файлом.

Как получить ссылку — конструктор показывает имя HTML-файла и конкретную ссылку GitHub Pages для этого специалиста. Скачайте файл, загрузите его в папку sites/specialists/. После загрузки используйте конкретную ссылку на HTML-файл этого специалиста, затем создайте QR-код или скопируйте ссылку.

Проверка правописания

Ошибки в редактируемых полях подчёркиваются красной линией средствами браузера. Нажмите по подчёркнутому слову правой кнопкой мыши и выберите правильный вариант.
